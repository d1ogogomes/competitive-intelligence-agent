# Briefing Semanal — Semana 2026-W22

## Resumo
- Cursor introduz "Shared Canvases" e a skill "/loop" para automatizações programadas.
- GitHub Copilot lança Claude Opus 4.8, abre source o Copilot para Eclipse e adiciona Gemini 3.5 Flash.
- Windsurf disponibiliza Claude Opus 4.8 e um novo modo Fast com preço diferenciado.
- Zed lança a série 1.4.x trazendo suporte a skills, AGENTS.md global e várias melhorias de UI e estabilidade.
- Claude reorganiza a documentação, refletindo mudanças de estrutura mas sem novas funcionalidades de produto.

## Claude
### O que mudou
- Reestruturação completa da página de documentação, com nova homepage e listagem de modelos, SDKs e recursos.
- Remoção da seção detalhada de modelos e pricing anterior.
### Relevância
- Alteração de apresentação que pode impactar desenvolvedores que consultam a documentação; sem mudanças de modelo ou pricing.

## Cursor
### O que mudou
- "Shared Canvases" permite partilhar canvas interativos.
- Skill "/loop" para agendar prompts recorrentes.
- Automations agora suportam múltiplos repositórios e automações sem repositório.
- Integração com Jira para iniciar agentes via tickets.
- Composer 2.5 com melhor inteligência e nova tarifação.
- Visual "Full-screen Tabs" e "Compact Chats" para UI mais enxuta.
### Relevância
- Expande colaboração e automação, facilitando fluxos de trabalho multi‑repo e integração com ferramentas de gestão.

## GitHub Copilot
### O que mudou
- Claude Opus 4.8 disponível no Copilot.
- Copilot Memory ganha controles de deleção e escopo.
- Modelos direcionados a organizações via regras.
- Copilot para Eclipse agora open‑source.
- Métricas de uso com URLs de download do GitHub.
- Seleção automática de modelo em VS Code.
- Busca semântica em Copilot Chat.
- Gemini 3.5 Flash GA no Copilot.
### Relevância
- Amplia opções de modelo (Opus 4.8, Gemini 3.5) e melhora controle de privacidade e métricas, além de abrir código para a comunidade.

## Windsurf
### O que mudou
- Claude Opus 4.8 disponível no Windsurf.
- Introduz Fast Mode com preço $10/$50 por milhão de tokens.
- Atualizações de bug e melhorias no agente local Devin, incluindo melhor contexto de arquivos e permissões persistentes.
### Relevância
- Novo modo de pricing oferece alternativa mais barata para cargas leves; atualização do agente local melhora a experiência de desenvolvimento.

## Zed
### O que mudou
- Lançamento da série 1.4.x (1.4.4, 1.4.3, 1.4.2) com correções e novas funcionalidades.
- Suporte a skills e arquivo global AGENTS.md.
- Possibilidade de escolher base branch na visualização de diff.
- Novas teclas de atalho e UI improvements (toggle all diff hunks, avatars, CSV preview). 
- Diversas correções de bugs críticos e melhorias de estabilidade.
### Relevância
- Fortalece a extensibilidade via skills e padroniza instruções de agentes; melhorias de UI e performance aumentam a produtividade.

## Sinais cruzados
- Tanto GitHub Copilot quanto Windsurf anunciam a disponibilidade de Claude Opus 4.8.
- Várias plataformas (Cursor, Zed) focam em melhorar automação e integração com ferramentas de desenvolvimento (skills, loops, multi‑repo).
