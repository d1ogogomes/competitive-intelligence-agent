# Briefing Semanal — Semana 2026-20

## Resumo
- Cursor adicionou ambientes multi‑repo, configuração como código e controles de segurança, além de integração com Microsoft Teams.
- GitHub Copilot anunciou o modelo base GPT‑5.3‑Codex para Business/Enterprise, retirou Grok Code Fast 1 e GPT‑4.1, e lançou métricas de uso por equipa, Cloud Agent com seleção automática de modelo e a CLI para JetBrains.
- Windsurf lançou Claude Opus 4.7 (modo rápido) e GPT‑5.5, introduziu Devin Review/Quick Review, Agent Command Center, melhorias de desempenho e correções de bugs, incluindo atualizações para Windows.

## Cursor
### O que mudou
- **Multi‑repo environments**: suporte a múltiplos repositórios num único ambiente de agente.
- **Environment configuration as code**: permite versionar a configuração do ambiente.
- **Governança e controles de segurança** para ambientes de agente.
- **Integração com Microsoft Teams**: delegar tarefas a agentes via "@Cursor".
- **Bugbot effort levels**: níveis de esforço customizáveis (default, high, custom).
### Relevância
- Facilita projetos com várias bases de código, melhora reutilização e segurança, apoiando equipas distribuídas. Integração Teams abre novas vias de colaboração corporativa.

## GitHub Copilot
### O que mudou
- **Base model**: GPT‑5.3‑Codex passa a ser modelo base para Copilot Business e Enterprise.
- **Depreciações**: Grok Code Fast 1, GPT‑4.1, GPT‑5.2 (e‑codex) e Claude Sonnet 4.
- **Novas funcionalidades**:
  - Métricas de uso ao nível de equipa disponíveis via API.
  - Copilot app em pré‑visualização.
  - Cloud Agent com seleção automática de modelo.
  - CLI Copilot para JetBrains IDEs e REST API para iniciar tarefas.
  - Preferências de utilizador para Copilot Memory (Pro/Pro+).
### Relevância
- Atualização para modelo mais avançado melhora qualidade das sugestões. Depreciações indicam foco nos modelos mais recentes. Métricas e API reforçam governança e integração empresarial.

## Windsurf
### O que mudou
- **Modelos**: lançamento de Claude Opus 4.7 (modo rápido) e disponibilidade de GPT‑5.5.
- **Devin Review & Quick Review**: revisão de código para todos os utilizadores, com trial de 2 semanas.
- **Agent Command Center**: nova visualização de lista de tarefas de agente, melhorias na barra lateral e desempenho.
- **Atualizações Windows**: correção de bug que impedia actualizações em alguns sistemas.
- **Correções de bugs**: estabilidade de servidores MCP, agente local Devin, e várias melhorias de performance.
### Relevância
- Modelos mais rápidos (Opus 4.7 fast) aumentam produtividade. Devin Review traz revisão automática a todos, melhorando qualidade de código. Melhorias de UI e estabilidade aprimoram a experiência geral.

## Sinais cruzados
- Tanto **Cursor** como **Windsurf** reforçam a capacidade de agentes multimodais e suportam múltiplos repositórios/ambientes, indicando uma tendência de facilitar projetos complexos distribuídos.
- **GitHub Copilot** e **Windsurf** introduzem novos modelos de IA avançados (GPT‑5.3‑Codex, Claude Opus 4.7 fast, GPT‑5.5), refletindo a corrida por modelos mais poderosos e eficientes.
- Depreciações de modelos antigos (Grok Code Fast 1, GPT‑4.1) são observadas em Copilot e Windsurf, sinalizando foco nos lançamentos mais recentes.
